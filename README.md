# Portfólio de Mineração de Dados

## Sobre o Projeto

Este projeto foi desenvolvido como atividade prática da disciplina de Mineração de Dados.

O objetivo é analisar o nível de maturidade digital das prefeituras brasileiras utilizando dados públicos do IBGE (Pesquisa de Informações Básicas Municipais - MUNIC 2024).

## Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## Funcionalidades

- Indicadores gerais dos municípios brasileiros
- Indicadores de maturidade digital
- Serviços digitais municipais
- Filtros por estado, região e porte populacional
- Visualizações gráficas interativas
- Insights automáticos sobre os dados

## Base de Dados

Fonte: IBGE - MUNIC 2024
